# Ευγενία Δήμα - Ψυχολόγος Ψυχοθεραπεύτρια Website

This is a clean, organized version of the website for Ευγενία Δήμα, a psychologist and psychotherapist in Athens, Greece.

## Project Structure

```
/
├── index.html            # Main website homepage
├── assets/               # Website styling assets
│   ├── css/              # CSS files
│   └── fonts/            # Font files
├── images/               # All website images
├── js/                   # JavaScript files (currently empty)
└── backup/               # Backup of the original mirrored site
    ├── eugene_site.tar   # Original tarball backup
    └── original_site/    # Original mirrored content
```

## Technology

The website uses:
- HTML5
- Tailwind CSS (via CDN)
- Minimal vanilla JavaScript

## Development

To modify this site:
1. Edit the `index.html` file directly 
2. Add any new images to the `images/` directory
3. Add any new CSS to the `assets/css/` directory
4. Add any new JavaScript to the `js/` directory

## Notes

This project was created by cleaning up an HTTrack mirrored site to maintain a simple, maintainable structure while preserving all original content and assets.
